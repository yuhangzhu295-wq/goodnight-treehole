## 一、这是什么

**晚安树洞是一个"夜里说话的地方"。** 它的核心假设是：人难受的时候不需要先想明白，只需要先把话说出来。

它做四件事：

1. **接住今晚的情绪** —— 你写下来，它给你一封温柔的回信。
2. **把一件事变成一段"旅程"** —— 不是给你鸡汤，而是帮你确认处境、给一个能落地的小行动，然后过几天回访你"后来怎么样了"。
3. **让走过同一条路的人互相说几句话** —— 匿名的、有边界的、72 小时到期。
4. **在你写不下去的时候先保护你** —— 检测到高风险内容时，先给求助资源，而不是继续聊天。

它**不是**心理咨询、不是社交软件、不是情绪打分工具。产品里明确不做健康评分。

## 三、主线流程（按"你想做什么"组织）

### 3.1 我只是今晚很难受，想说点什么

1. 打开 App → 落在**今晚**页。
2. 在输入框写下来（上限 1000 字，**"你也可以只写一句"**）。
3. 或者点下方的**快捷短语**（"今晚从哪里开始"那一行）—— 点"感情"会弹出一张卡片问你**"这段感情里，什么最让你难受？"**，列出常见场景，也可以选**"说不清，也可以直接写"**。
4. 点**「继续」**（提交中会变成"正在开始整理…"）。
5. 系统会整理出一段**旅程**，并给你一封**今日回信**。
6. 如果你不想整理，页面上也写了：**"如果你不想立刻整理，我也可以先陪你待一会。"**

### 3.2 我想把一件事真正推进下去

1. **今晚**页写下来 → 点**「继续」**，创建旅程。
2. 进入**旅程详情** → 选择**意图**（"我想…"，例如"先走一小步"）。
3. **确认处境** —— 系统整理的"事实/感受/需要/限制"，你确认后 **AI 不能再改写**（这是硬保护）。
4. 点**生成行动计划** → AI 给一个可执行的小步骤。
5. 点**添加行动承诺** → 生成一条行动，并自动安排一次回访。
6. 到**行动**标签 → 打卡：**「完成了」/「做了一部分」/「没有完成」**，可以补一句"记下这次结果"。
7. 过几天会收到**提醒与回访**通知，回来写下"这一小步带来了什么变化？"
8. 走完之后 → 旅程详情 → **「走完了，结束这段旅程」**。
   ⚠️ **产品规则：必须完成过至少一个行动才能毕业。** 否则会提示"完成至少一个小行动后才能结束旅程"。

### 3.3 我写的内容里出现了很重的信号

系统识别到高风险内容时，会**先保护你**：

1. 创建旅程时直接进入**安全优先**状态。
2. 跳到**安全支持**页（标题：**"现在先优先保护你自己"**），给求助资源和"信任联系人"。
3. 后台同时生成一条**安全事件**，管理员能看到触发原文并处理（写审计日志）。
4. 你点**「我知道了」**确认看过。

> 这一步是**原子**的：旅程和安全记录要么一起写成，要么都不写。不会出现"有高风险旅程但没有安全记录"的情况。

### 3.4 我想和走过同一条路的人说几句

1. 先去**同路**页 → 点**「允许匿名寻找同路经历」**（默认是关的，需要主动开）。
2. 在**旅程详情** → **找同路人** → 系统按处境相似度推荐。
3. 点进某条经历 → **「递出匿名请求」**，可以附一句请求理由和一个问题。
4. **对方（经历发布者）**在**我的请求**里选择**「我愿意聊聊」**或**「这次先不了」**。
5. 对方接受后 → **双向同意页**（"开始前，先确认边界"）→ **「同意并开始同行」**。
6. 进入**会话**（最长 **72 小时**），可以发消息，也可以点**「帮我整理一下」**让 AI 帮你把想说的话理一理。
7. 结束时点**「结束」** → 可以**「留下感受」**，也可以**举报**。

### 3.5 我想用工具，不想整理整件事

**我的 → 情绪工具**，共 9 个（见 4.7）。

## 四、逐页说明

> 格式：**页面** → 用途 → 按钮清单。
> 「‹」是返回，「×」是关闭弹层，「···」是更多操作。

### 4.1 今晚（首页）

**用途**：夜间入口。承接情绪，或者回到你正在走的那段路。

- 顶部：**「晚安树洞」** 品牌 + 右上角**铃铛**（带未读数，点进提醒与回访）
- 主标题：**"今晚怎么了？"** / 副标题 **"不用整理好再说，先把它放在这里。"**
- 输入框：占位文字 **"比如：我今天又想起他了，心里很乱，不知道该怎么办……"**
- 快捷短语行：**"今晚从哪里开始"** —— 每个词是一个快捷入口
- 有进行中的旅程时，出现**"你已经在走的一段路"**卡片 + **「继续 ›」**
- 一句陪伴：**"如果你不想立刻整理，我也可以先陪你待一会。"**
- **「继续」** —— 提交，创建旅程（提交中显示"正在开始整理…"）
- 感情场景弹层：**"这段感情里，什么最让你难受？"** + 场景按钮 + **「说不清，也可以直接写」**

### 4.2 写下心情 / 发布树洞

- **写下心情**（`/pages/mood/create`）：标题**"写下心情"**，输入框**"此刻的你，想说些什么呢？开心的、难过的、烦恼的，都可以告诉树洞哦～"**，按钮 **「发布心情」**。
- **树洞广场**（`/pages/square/index`）：标题**"晚安树洞"**，浏览公开内容。按钮：**「写心情」**、**「♡ 抱抱」**、**「☺ 回应」**、**「复制内容」**、**「举报」**、**「不感兴趣」**。
- **树洞详情**（`/pages/post/detail`）：**「♡ 抱抱」**、**「回应」**、**「收藏 / 已收藏」**、**「发布回应」**、**「复制内容」**、**「举报」**、**「屏蔽」**，以及**回应预设**（一键套用常用回应文案）。

### 4.3 今日回信 / 回信列表

- **今日回信**（`/pages/letter/index`）：标题**"今日回信"**。按钮：**「完成」**、**「重新读取」**。
- **回信详情**：**「收藏回信 / 取消收藏」**、**「查看今日回信」**。
- **我的回信**（`/pages/letter/list`）：筛选 **「全部 / 未读 / 已收藏」**；每条有 **「♡ 数字」**（喜欢）、**「☆ 收藏 / 已收藏」**、**「查看全文 ›」**、**「写下心情」**。

### 4.4 旅程详情

**用途**：一段"想解决的事"的全过程页面 —— 处境、意图、行动计划、时间线、同路人、归档、毕业。

按钮：**「继续陪伴」**、**「归档这段旅程」**、**「走完了，结束这段旅程」**、**「再陪一会儿」**、**「确认结束」**、**「确认归档」**，毕业时可选 **「愿意匿名分享」/「以后再说」/「不分享」**。

> 关键保护：**处境一经你确认（`user_confirmed`），AI 的后续回调不会把它改回草稿。** 这一条有专门的回归测试。

### 4.5 行动中心

**用途**：今天只需要做的那一件事。标题**"今晚，只做这一件事"**。

- 打卡三选一：**「完成了」/「做了一部分」/「没有完成」**
- **「记下这次结果」**（占位："写一句就好，也可以留空。"）
- **「保存这次回顾」**（占位："这一小步带来了什么变化？"）
- 两个"缓冲"按钮：**「先放一晚」**、**「先留在这里」**（占位："想先留住的一句话"）
- 决定相关：**「这个决定现在最让你为难的是什么？」**

> 幂等保护：重复打卡**不会**改写已经结束的打卡记录。

### 4.6 同路（匿名互助）

- **同路首页**（`/pages/peers/index`）：标题**"有人也走过"**。标签 **「推荐给你」/「我的请求」**；按钮 **「允许匿名寻找同路经历」**（首次需开启）、**「看看隐私边界」**、**「换一批」**、**「›」**进入详情。
- **经历详情**：**「请求匿名交流」** → **「递出匿名请求」**。
- **我的请求**（`/pages/peer/requests`）：**「收到的请求」/「推荐给你」**；处理按钮 **「我愿意聊聊」/「这次先不了」/「暂时不想」/「确认这段同行」**。
- **等待页**（`/pages/peer/wait`）：**「刷新状态」**、**「返回同路」**。
- **边界确认**（`/pages/peer/consent`）：标题**"开始前，先确认边界"**，按钮 **「同意并开始同行」** / **「我想再想想」**。
- **会话**（`/pages/peer/conversation`）：**「帮我整理一下」**（AI 帮你理想说啥）、**「发送」**、**「留下感受」**、**「结束」** → **「确认结束」**、**「提交举报」**、**「停止匹配并结束」**。
- **毕业分享**（`/pages/peer/graduate`）：**「愿意匿名分享」/「以后再说」/「先不分享」**，可**「想留下一句话（可选）」**。

### 4.9 决定保险箱

`/pages/decision/index`，标题**"先把这个决定放这里"**。

## 五、隐私设置（14 个开关）

路径 `/pages/settings/privacy`。页面说明原文：**"隐私设置会保存到后端，影响新心情的默认可见范围、真人回应和月报分享偏好。"**

**默认值是这套设计的关键：凡是涉及"长期保留你的个人数据"和"AI 记住你"，默认全部关闭；匿名类默认开启。**

| 开关 | 默认 | 控制什么 |
| --- | --- | --- |
| 默认可见范围（`defaultVisibility`） | `PRIVATE` | 新发内容的默认可见性 |
| 允许匿名公开 | ✅ 开 | 内容可匿名出现在公开区 |
| 允许真人回应 | ✅ 开 | 别人可以回复你的树洞 |
| 允许生成月报分享图 | ✅ 开 | 月报能否导出成图片 |
| 允许同路匹配 | ✅ 开 | 能否被推荐给同路人 |
| 允许匿名经历统计 | ✅ 开 | 匿名统计 |
| **保存生活恢复记录**（`allowRecoveryData`） | ❌ **关** | 关着时打开"恢复"页会提示**"请先在隐私设置中允许查看恢复记录"** |
| 允许旅程长期分析（`allowJourneyLongTermAnalysis`） | ❌ 关 | 长期分析 |
| **允许 AI 使用历史记忆**（`allowLongTermMemory` / `allowAiMemoryUse`） | ❌ **关** | 关着时 AI 不会引用历史 |
| **允许匿名分享同路经历**（`allowAnonymousExperienceShare`） | ❌ **关** | 关着时发布经历会提示**"请先在隐私设置中允许匿名留下经历"** |
| 允许保留旅程归档（`allowJourneyArchiveRetention`） | ❌ 关 | 关着时归档会被拒绝 |
| 允许未来信提醒（`allowFutureSelfNotifications`） | ❌ 关 | 未来信到期是否提醒你 |
| 允许导出我的数据（`allowDataExport`） | ❌ 关 | 导出功能 |

另外还有三个按钮：

- **「清空本地缓存」**
- **「导出我的日记」**
- **「删除我的数据」** → **「暂不删除」/「确认删除」** —— 说明原文：**"这会通过服务端删除你的日记、回信和收藏记录。删除后无法恢复。"**

> ⚠️ 走查时踩到的点：**默认关闭的开关会让对应页面直接 403 并提示去哪开。** 这是设计如此，不是故障。

**同路经历**页需要人工审核（`pending_review` → `published`），审核通过后才会出现在同路推荐里。

## 八、已跑通的完整业务流

两条走查脚本都跑在**真实运行的开发环境**上（不是测试替身），脚本与完整日志在 `docs/product-manual/`：

| 走查 | 步数 | 结果 | 覆盖 |
| --- | --- | --- | --- |
| `walkthrough-live.mjs` | 54 | **54 PASS / 0 FAIL** | 今晚 → 写信 → 旅程 → 意图 → 处境确认 → 行动计划 → 行动 → 打卡 → 时间线 → 安全路径 → 同路全链路 → 工具 → 个人中心 → 后台 → 安全边界 |
| `walkthrough2.mjs` | 35 | 32 PASS / 3 例为设计拦截 | 归档、毕业、树洞广场（抱抱/回应/收藏/举报）、日记、有限记忆、支持计划、稳定的我、恢复、信任联系人、FAQ/反馈、信件操作、月报、决定保险箱 |

**关键实体链路（一次走查产生的真实数据）：**

```
mood（写下心情）
  → letter（今日回信）→ 已读 / 存进日记
  → journey（旅程）+ situationSnapshot（处境）+ journeyUpdate（时间线）
      → intent（意图）
      → situation 确认（confidence = user_confirmed）
      → actionPlan（AI 行动计划）
      → actionCommitment（行动）→ outcomeCheckin（打卡 completed）
      → peerExperience（同路经历，另一用户）→ 后台审核 published
      → peerMatch（匹配）→ requested → connected → peerConversation（72h 会话）
  → safetyEvent（高风险，与旅程同事务写入）→ 后台 handled + auditLog
  → decision（决定保险箱）→ cooldown（冷静期）
```

**3 例"未通过"是产品设计好的拦截，不是缺陷：**

1. **恢复归档 → 400**："只有手动归档的旅程可以恢复；已完成的旅程会保留在归档中"
2. **毕业同意 → 400**："请先完成这段旅程"（需先有 `completed` 状态）
3. **稳定的我 → 400**："请至少写下一条属于你的稳定状态信息"（字段名需为 `stableDescription` 等，走查脚本字段名写错）

另外第一遍走查里有 4 例一开始"失败"，查明后同样是设计拦截或脚本问题：三个是**隐私开关默认关闭时的 403 提示**，一个是脚本漏传 `status` 字段。

## 九、已知限制与注意事项

1. **AI 是真实调用，不是模拟。** 但本地环境 `.env` 里 `DAPI_API_KEY` 是空的，所以所有 AI 功能会走到**兜底模板**（界面上会显示一条明确的降级提示，不会假装成功）。填上真实 key 之后 AI 才会真正生成内容。
2. **整个应用目前只能单实例运行。** 八个核心模型（旅程、行动、打卡、通知、安全事件、AI 任务等）已经改成直接读写数据库，本身是并发安全的；但另外 35 个模型还是进程内内存状态，**A 实例写的数据 B 实例 reload 前看不到**。所以不要同时起两个 API 指向同一个库。
3. **默认隐私是全关的。** 第一次用的时候，恢复记录、AI 记忆、匿名分享经历、未来信提醒这些都会提示"请先去隐私设置开启"。这是刻意的。
4. **同路匹配需要两个用户。** 单账号看不到完整的互助链路（要一个人发经历、另一个人请求）。
5. **后台需要管理员账号。** 默认 `admin`，密码在走查中用的是 `admin123`（重建数据库后验证过登录成功，但请以实际配置为准）。
6. **物理安卓设备没接。** 之前是用模拟器验证的；真机没测过。
