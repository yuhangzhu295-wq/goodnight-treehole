# 晚安树洞产品逻辑审计

更新时间：2026-08-07

## 真实架构

- `apps/mp`：Vue 3 用户端，14 张前台参考图对应 13 个路由与 1 个详情回复抽屉状态。
- `apps/admin`：Vue 3 管理端，覆盖登录、总览、用户、内容、回应、AI、反馈、配置、审计。
- `apps/api`：NestJS API，统一承载用户端和管理端业务。
- PostgreSQL：`127.0.0.1:55432/goodnight_treehole`，Prisma 关系表与 `RuntimeState` 同步持久化。
- Ollama：`127.0.0.1:11434`，启动时发现模型，生成任务写入真实 `AIJob`。

## 核心闭环

用户情绪记录 -> 私密日记或匿名树洞 -> AI Router -> AIJob -> 模型输出 -> 回信/工具/成长统计；公开内容与真人回应由后台审核，反馈由后台回复和解决。

## 本轮发现并修复

- 恢复 Ollama 自动发现、Provider 持久化和 benchmark，删除旧的 `LOCAL_MODEL_DISABLED` 阻断。
- 修复后台路由接口只能保存 CLI Proxy/DeepSeek 的硬编码限制。
- 将“本地模型优先”从无效配置改为真实本地/远程路由切换。
- 修复日记相对媒体 URL 指向前台端口导致的破图，并补 `/uploads` 开发代理。
- 将 API、business、cross 测试强制隔离到独立 PostgreSQL 测试库。
- 修复后台反馈“回复后解决”的真实流程和登录输入可访问名称。

## 结论

功能、数据、AI 与跨端主链路已具备当前证据；视觉结构检查通过，但 23 个设计参考页仍高于 5% 像素差异阈值，因此项目状态仍为 `IN_PROGRESS`，不能宣称全量视觉验收完成。
